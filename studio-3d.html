Confidentialité : l'outil de génération est hébergé par Hugging Face, un service externe. Les images importées dans l'atelier lui sont transmises pour le traitement. N'y envoie pas de photo personnelle ou de document confidentiel. La disponibilité et le temps d'attente dépendent du service hébergeur.
1. Importer

Choisis une image nette avec un seul objet bien visible, idéalement sur un fond simple.

2. Générer

Lance « Generate Shape », puis « Apply Texture » pour obtenir un modèle texturé.

3. Exporter

Utilise « Download GLB » pour récupérer ton objet 3D et le réutiliser dans tes projets.

Eneles Motion utilise le projet open source TripoSG et son espace de démonstration hébergé. Code source TripoSG · Espace de génération
